# Security reports

For vulnerabilities affecting private data or someone else's machine, use
[GitHub private vulnerability reporting](https://github.com/phobos-dthorga/phobos-rimworld/security/advisories/new).
Do not post secrets or unredacted exploits in public issues. If private reporting is unavailable, open a
minimal issue asking for a private contact route, without sensitive details.

Include the revision or version, the impact, steps to reproduce and a synthetic example where possible.
Maintenance is best-effort for the current development version, with no guaranteed response time and no
support window for old versions. Gameplay bugs belong in
[Issues](https://github.com/phobos-dthorga/phobos-rimworld/issues/new/choose).
