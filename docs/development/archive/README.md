# Archived records

Design and research records kept **unchanged**, for their history: what was asked, what was weighed and why. They do not say how
anything works now; each system's living page does ([systems](../systems/README.md)), and its decisions are in
[the decision logs](../decisions/README.md).

- **Moved, never edited.** A record keeps its file name here. Changelog entries and code comments may still name it by its old
  path, `docs/development/<name>.md`: look for the same name in this folder.
- **Links inside a record are as written.** A link that broke in the move is fixed only where the link check requires it.
